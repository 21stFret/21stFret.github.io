2D shadows that know how tall things are

A technical write-up of the shadow system from my current project.

The problem

Unity's built-in 2D shadows ignore how tall a sprite is, so shadows stretch on forever. That breaks the look of a top-down game with a day and night cycle.

My approach

Each object gets a darkened copy of its own sprite. The system angles and stretches that copy from the sun's position, using a fake height for the object so shadows are long at dawn and dusk and short at midday.

A central manager keeps every shadow in sync with the sun, cleans up duplicates, and updates live in the editor, so artists see the result while they place objects.

Trade-offs

Sprite copies are simple and look right, but they cost a draw call each. For very large scenes the next step would be moving the projection into a shader.
